01運作方式How it works

每個需求，都走同一條路Every request takes the same route

你只要說出需求。Way Tools 在本機判斷路線、選出能力、執行並檢查，結果回到工作區，下一步可以接著用。Just say what you need. Way Tools picks the route on your device, chooses a capability, runs it and checks the result, which returns to the workspace for the next step.

從需求到結果From intent to result
  1. 說出需求Intent
  2. 帶入內容Context
  3. 判斷路線Router
  4. 選出工具Capability
  5. 執行Action

路線選擇的順序Routing order

  1. 1

    已驗證的能力Verified capability 實驗中Experimental

    重用之前成功、並通過驗證的做法。Reuse an approach that worked before and passed verification.

  2. 2

02能力養成Capability graduation實驗中Experimental

一次成功，變成下一次的能力Turn one success into reusable capability

Way Tools 不希望每次都重新問 AI。重複、可重播、可驗證的做法，可以逐步變成穩定能力。這項能力學習目前仍屬實驗功能。Way Tools should not ask AI again for work it already knows. Repeated, replayable and verifiable behavior can become a stable capability. Capability learning is currently experimental.

  1. 01

    重複Repeat

    同一類本機工作多次成功，累積最少必要證據。Repeated local work accumulates only the evidence needed to recognize a pattern.

  2. 02

    重播Replay

    候選做法重新執行，不因「曾經成功」就直接相信。The candidate is replayed instead of being trusted merely because it worked before.

  3. 03

    驗證Verify

    獨立檢查結果；失敗就停止升級。An independent check verifies the result. Failure stops graduation.

  4. 04

    穩定能力Stable capability

    下次優先重用已驗證做法；若驗證失敗，能力會降級而不是硬撐。Verified behavior is reused first. If verification later fails, it degrades instead of pretending to be reliable.

    ↺驗證失敗就降級Degrades on failure

能力可以累積，權限不會。Capability can compound; authority does not.重複使用不會自動增加瀏覽器、檔案、供應商或其他敏感權限。Repeated use never automatically grants browser, file, provider or other sensitive authority.

03工作區Workspace

一個工作區，五個入口One workspace, five ways in

不用記住工具放在哪裡。從對話、百寶箱、計畫、工具庫或 My Way 開始，結果都回到同一個工作區。You do not need to remember where a tool lives. Start from chat, the toolbox, plans, your library or My Way; the work returns to the same workspace.

  • Chat

    說出你要做的事Say what you need

    Way Tools 先找本機已有能力，再決定是否需要其他方法。Way Tools checks local capabilities first, then decides whether anything else is needed.

  • Toolbox

    直接使用百寶箱Use the toolbox directly

    需要確定性工具時，直接打開就用，不需要模型。Open deterministic utilities directly when you want them. No model required.

  • Plans

    把一句話變成計畫Turn a sentence into a plan

    用自然語言建立本機計畫與提醒；不確定時先澄清，不偷偷猜。Create local plans and reminders from natural language. Ambiguity is clarified instead of guessed.

  • Library

    把重要內容留下來Keep what matters

    保存連結與內容，整理、標記、封存，之後再找回來。Save links and content, organize and archive them, then retrieve them later.

  • My Way

    累積你的使用方式Build up your way

    常用工具與已驗證能力留在這裡；能力可以累積，權限不會自動擴張。Keep favorite tools and verified capabilities here. Capability can compound; authority does not expand automatically.

同一個工作區One workspace

結果回到這裡，從任何入口都能接著用。Results return here, so any entry point can pick up where you left off.

05隱私、安全與花費Privacy, security and cost

看得見，也管得住Visible, and under your control

能在本機完成的事，不會用到外部 AI。真的需要時，每一步都先經過你。Anything your device can do never touches outside AI. When it's truly needed, every step goes through you first.

資料預設留在裝置上Data stays on your device by default

你在 Way Tools 裡的資料，預設保存在這台裝置與瀏覽器裡，不會自動共享。Your Way Tools data is kept on this device and in this browser by default, and is not shared automatically.

本機儲存Local storage·不自動共享Not shared automatically

外部 AI 花費可設上限Set limits for outside-AI spending
